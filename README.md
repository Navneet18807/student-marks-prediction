# Student Marks Prediction using Linear Regression

This project predicts student marks based on the number of hours they studied using a simple Linear Regression model.

## Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
scikit-learn


##  How to Run
1. Clone the repo or download the files
2. Open `student_marks_prediction.ipynb` in vs operator
3. Run all cells step-by-step to see data cleaning, EDA, model training, and prediction

##  Output Example
- Scatterplot of actual vs predicted marks
- Evaluation metrics: MAE, MSE, RMSE
